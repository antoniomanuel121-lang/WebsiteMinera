## Publicação

O GitHub Actions publica automaticamente a branch `main` após cada commit. O site utiliza o prefixo `/WebsiteMinera/` no GitHub Pages.

## Desenvolvimento local (opcional)

```bash
npm install
npm run dev
npm run build
```
