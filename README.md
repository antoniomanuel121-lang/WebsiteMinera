# MINERA — Website

Website da Minera, desenvolvido com React, TypeScript, Vite e Motion.

## Desenvolvimento local (opcional)

```bash
npm install
npm run dev
```

## Publicação

O workflow `.github/workflows/deploy.yml` publica automaticamente no GitHub Pages a partir do ramo `main`. Em **Settings → Pages → Build and deployment**, selecionar **GitHub Actions**.

O endereço previsto é `https://antoniomanuel121-lang.github.io/WebsiteMinera/` após a primeira publicação bem-sucedida.
